# \# YouTube Transcript Summarizer

# 

# An AI-powered application that converts YouTube video transcripts into concise, easy-to-understand notes using Google's Gemini AI.

# 

# \## Overview

# 

# The YouTube Transcript Summarizer helps users save time by extracting transcripts from YouTube videos and generating concise summaries of their content.

# 

# Instead of watching an entire video, users can get the key information in a structured summary.

# 

# \## Features

# 

# \- Extracts transcripts from YouTube videos.

# \- Generates AI-powered summaries using Google Gemini.

# \- Presents summaries in a simple Streamlit interface.

# \- Displays the video's thumbnail when a valid link is provided.

# \- Generates summaries of up to 250 words.

# 

# \## Tech Stack

# 

# \- Python

# \- Streamlit

# \- Google Gemini AI

# \- YouTube Transcript API

# \- Python-dotenv

# \## Setup and Installation

# 

# 1\. Clone this repository:

# 

# ```bash

# git clone YOUR\_GITHUB\_REPOSITORY\_URL

# ```

# 

# 2\. Navigate to the project directory:

# 

# ```bash

# cd youtube-transcript-summarizer

# ```

# 

# 3\. Install the required dependencies:

# 

# ```bash

# pip install -r requirements.txt

# ```

# 

# 4\. Create a `.env` file in the project directory and add your Google API key:

# 

# ```text

# GOOGLE\_API\_KEY=your\_google\_api\_key

# ```

# 

# 5\. Run the application:

# 

# ```bash

# streamlit run app1.py

# ```

# 

# \## How to Use

# 

# 1\. Launch the application.

# 2\. Enter a YouTube video URL.

# 3\. Click \*\*Get Detailed Notes\*\*.

# 4\. View the AI-generated summary.

# 

# \## Configuration

# 

# A valid Google Gemini API key is required to generate summaries. Keep your API key private and never upload your `.env` file to GitHub.
